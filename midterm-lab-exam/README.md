# Cougar Men E-Commerce Website

## Project Overview
This project is a static, responsive e-commerce website inspired by the Cougar Pakistan online store. It showcases a men's clothing and footwear collection with a homepage and a product detail page.

## Reference Website
- **Website Name:** Cougar Pakistan
- **Website URL:** https://cougar.com.pk/

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5

## Features
- Responsive navigation bar
- Hero section with a shopping button
- Product category sections
- Product cards displaying images, names, and prices
- Product detail page for the Classic T-Shirt
- Quantity selector on the product detail page
- Add to Cart buttons (visual only; no cart functionality)
- Footer with customer support and company information
- Responsive layout for desktop, tablet, and mobile screens

## Project Structure
- `index.html` — Homepage and product listings
- `product.html` — Product detail page
- `style.css` — Website styling
- `Images/` — Website images

## How to Run
1. Download or clone this repository.
2. Open the `assignment-2` folder.
3. Open `index.html` in a web browser.

## Note
This is an academic front-end project. It does not include a backend, database, or functional shopping cart.
